# LazyEng 家庭版 V1.0 交付与侧载指南

## 版本与证据入口

本次交付以代码基线 `521c58d` 为起点，版本为 `1.0.0` / `versionCode 2`，数据库保持 Schema 6，不新增迁移。旧 `31729f5` 已在基线历史中，不作为本次新增交付。

本次版本、安装包大小、SHA-256、签名和实测证据统一见 [ADR0034：V1.0 发布包与交付](../adr/0034-v1-release-package-and-delivery.md)。验收结果以ADR0034当前证据为准。旧 [ADR0034：私有签名与交付](../adr/0034-private-release-signing-and-delivery.md) 仅保留历史签名决策与记录，不作为本次包已验收的依据。发布范围与已知问题见 [V1.0 发布说明](v1.0-release-notes.md)。

## 安装与升级

最低系统要求为 Android 8.0（API 26）；此要求不代表已覆盖全部兼容设备。新装 E2E、多设备、平板等验收范围以本次证据入口为准。

1. 将已签名的 `app-release.apk` 传到手机，用文件管理器打开。
2. 如提示安装权限，按系统引导允许该文件管理器“安装未知应用”；确认安装后可关闭此权限。
3. 更新时选择覆盖安装，不卸载旧版、不清除应用数据。必须使用同一签名的包；遇到签名冲突请停止安装并联系维护者，勿为安装而删除家庭数据。
4. 新设备首次打开时设置自己的家长 PIN，创建孩子档案并选择学习等级。旧设备更新后应保留原档案。

私钥仅存于维护者本机仓库之外。请安全保管密钥及密码，勿随安装包分发。备份不得由测试脚本自动删除。

## 导入视频和字幕

1. 在孩子端“我的”或首页进入家长控制台，验证家长 PIN。
2. 使用系统文件选择器选择有权使用的本地视频及对应英文或中英混排 SRT/VTT 文件。也可授权一个目录查找同名字幕候选；候选不会自动关联，仍需选择、预览并确认发布。没有字幕时可先保存视频，待英文字幕就绪且媒体可访问后才进入孩子可播放列表。
3. 导入保留原视频位置与文件访问授权，不复制视频。不要移动、删除原视频或回收授权；仅保留应用或 JSON 备份不能替代原视频。
4. 在视频与内容管理中检查孩子可见开关。返回视频库后可按等级/筛选条件查看；找不到视频时先检查字幕状态、可见性和筛选。
5. 播放器支持英文/双语/隐藏字幕；识别出已有中文时才可选“仅中文”。手机竖屏使用下方剧本，不在视频上叠字幕；紧凑横屏可展开字幕列表，控制栏隐藏后显示视频底部字幕。点英文词查词、发音、收藏，点击句子回放。

### 支持格式与字幕边界

- 视频入口选择 `video/*`；源码不按扩展名列出全格式白名单，而是探测时长、尺寸、音视频轨和可解码首帧。优先使用 MP4（H.264/AAC）；其他容器和编码取决于设备与 Media3，不保证 MKV、WebM 等任意文件均可用。
- 外挂字幕仅支持 `.srt`、`.vtt`，单个文件上限为 4 MiB；不支持直接导入 ASS/SSA，也不从视频内自动抽取字幕。
- 编码支持 UTF-8、UTF-16LE、UTF-16BE、GBK；优先使用 UTF-8。自动识别不确定时按提示手动选择真实编码，不保证自动猜中 GBK。预览可调整整体偏移（±5000 ms），重新校验后再发布。
- 字幕按纯文本处理；部分基础样式标签会被移除，WebVTT 的 STYLE、REGION、定位参数及不支持的标签会报错。遇到此类文件应重新导出为无定位样式的 SRT/VTT。
- 中英混排字幕及播放器语言投影是基线已有能力，偏离旧版仅英文白名单，本次不新增。投影按同一字幕句内“英文在前、中文在后”的文本拆分，不是自动翻译，不保证识别所有混排方式；无中文源文本时不会生成译文。家长应在预览及播放时核对对应关系。

系统 TTS 发音依赖设备的英文语音服务/语音包；出现英文语音不可用时，到系统文字转语音设置安装英文语音。需要离线发音时，请事先准备支持离线的英文语音包；视频原声与本地释义不依赖 TTS。

## 离线使用和 AI 设置

无需 API Key 即可使用本地视频、字幕、离线词典、生词收藏和闪卡。生词本可以回跳原句，复习评级会保存下次复习时间。

需要 AI 时，在家长控制台“大模型设置”选择服务商，填写 HTTPS API Base、模型和自己的 API Key，测试连接后保存。兼容服务支持以 `/v1` 结尾的嵌套路径。Key 不要发到聊天、截图或备份中；重新打开界面只显示掩码。Release 不允许 HTTP，包括局域网 HTTP Ollama；请使用 HTTPS 服务。测试连接可能产生供应商费用，请确认额度和模型权限。

无网、超时或未配置时 AI 区域降级，本地查词仍可用。AI 内容不是教师或权威词典判断；家长可结合原句核对。

## 备份、恢复、卸载与管理

- 家长验证 PIN 后进入“数据与存储管理”，选择“导出家庭 JSON 备份”。将导出文件另存到家长安全保管的位置；其中有家庭学习信息，不应公开分享。导出排除 PIN、API Key 和内部媒体绝对路径。
- JSON 导出不是手机完整镜像，也不包含原视频、系统文件授权及 Keystore 密钥。请另行保留有权使用的原始视频和字幕。
- V1.0 尚无经过端到端验收的跨设备一键恢复流程。不要为了测试备份而卸载、清数据或替换数据库；有恢复需求先联系维护者，保留旧设备与原始文件。不能承诺导出的 JSON 可自动还原全部学习状态。
- 覆盖升级沿用 Room v1→v6 的有序迁移，本次不新增 Schema、不使用破坏性迁移。遇到迁移失败应保留旧数据排查，不清库重试。禁止用版本号较低的 APK 强行降级。
- 卸载或“清除全部数据”会丢失本机档案、学习记录、PIN/AI 配置及应用私有媒体副本；系统文件选择器之外的原始媒体应自行妥善保管。忘记 PIN 无通用后门，不要尝试演示 PIN。
- 成员删除、视频物理删除和清缓存均需确认；家庭必须至少保留一个孩子。删除孩子会清理其学习数据，清缓存前检查分类和影响范围。

## 常见问题

| 现象 | 建议 |
| --- | --- |
| 安装提示签名冲突 | 停止；请维护者确认原签名证书，不卸载换包 |
| 视频不可播放 | 核查文件仍存在、系统文件授权、字幕已发布与孩子可见性；重新授权应由家长操作 |
| 文件格式不支持 | 优先使用 Android 可解码的 MP4（H.264/AAC）；其他容器/编码取决于系统与 Media3，未作全格式保证 |
| 字幕乱码/时间不准 | 用 UTF-8 SRT/VTT，检查时间码；在家长预览中选正确编码或调整偏移后再发布 |
| 查词首次略慢 | 内置压缩词典首次在本地解压并校验，无需下载；空间不足时先按提示处理 |
| AI 无法连接 | 核查 HTTPS 地址、模型权限、额度与网络；不要把 Key 发到日志或聊天，本地学习可继续 |
| 无法截图 | 安全窗口可能限制截图；不要关闭安全保护来记录 PIN/Key |

## 版本核销与限制

| 模块 | 交付能力与验收边界 |
| --- | --- |
| T0 / E1 / EH | 工程、设计系统、家庭/Profile/PIN、四 Tab 导航与隔离；本次不重复全新安装清空实机 |
| E2 / E3 / E4 / E5 | 本地视频/字幕、播放器、剧本点词、离线词库、去重事件；竖屏不叠字幕遮挡视频 |
| E6 | 安全配置、Provider、校验缓存、异步解释与降级；AI 需要网络和用户额度 |
| E7 | 生词列表、语境回播、确定性闪卡排程；非高级记忆算法 |
| E8 | PIN 后的模型、成员、内容、存储管理；仅本地家庭使用 |
| INT-1 | 既有隔离端到端证据；不能等同本次混淆 Release 的全新安装验收 |
| INT-2 | 深浅主题、部分热区/大字体覆盖；闪卡背面实体旋转及播放器倍速/循环旋转仍待补测 |
| INT-3 | 冷启动、热查词、离线隔离闭环、迁移和 WAL 中断证据；非全量性能/隐私证明 |

TalkBack、平板、折叠屏、分屏家庭自用暂不覆盖。长期播放泄漏、长字幕/大网格 60fps、写入中 `kill -9` 与全私有目录明文扫描仍未验收。看板不得把断点进度当累计观看分钟；缺少真实时长数据时显示暂无记录。

YouTube、自动翻译、ASR、学习关怀等为 V1.1 范围，不随 V1.0 交付。ECDICT 署名见资产 `ECDICT-NOTICE.txt`、[ADR 0016](../adr/0016-ecdict-import-and-lookup.md)；个人家庭许可风险接受见 [ADR 0004](../adr/0004-dictionary-license-and-sizing.md)，不代表公开或商业分发授权。

安装包版本、大小、SHA-256、签名和本次实机证据见 [ADR 0034](../adr/0034-private-release-signing-and-delivery.md)。本包面向家庭试用交付，不宣称官方所有设备/性能验收项全部通过。
