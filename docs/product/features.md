# LazyEng 家庭版 — 功能清单

> 基于 PRD v2.2，面向 8 岁儿童（剑桥 Power Up 2 水平）的视频学英语家庭版原型。

## 孩子端

### 首页
- 当前 Profile 头像与快速切换、今日护眼时长提醒（HOME-02）
- 继续观看大卡片：封面、标题、剩余时长进度条、一键继续播放（HOME-01）
- 今日成就看板：观看分钟数、查词数、待复习生词数
- 精选 / 最近导入视频瀑布流，展示建议等级与字幕就绪状态（HOME-04）

### 视频库
- 封面列表，按等级 / 主题 / 来源筛选
- 视频详情入口，展示建议等级标识（人工 / 估算）（VID-03）

### 沉浸式播放器（核心）
- 模拟视频视口 + 悬浮精简控制条：播放/暂停、进度条、0.8x/1.0x 倍速、单句复读高亮开关（PLY-01/PLY-04）
- 逐句滚动字幕，当前句高对比高亮（PLY-02/PLY-03）
- 句子内每个英文单词为独立可点击 Token，带水波纹反馈
- 底部辅助栏：字幕语言切换（英/双语）、本集重点词入口（PLY-05）

### 语境词典底部弹窗（灵魂功能）
- 本地释义首屏（300ms 模拟）：原形、音标、发音喇叭、词性、简明中文（≤24 字）（DIC-01）
- 语境原句与时间溯源：目标词高亮、时间戳、回到原句播放
- AI 语境增强卡片：童趣"为什么在这里是这个意思"（≤80 字）+ 低难度例句，含异步加载 / 降级 / 重试态（AIC-01~AIC-04）
- 底部主操作：加入生词本（收藏动画）、标记已掌握（DIC-05）

### 生词本与原句复习闪卡
- 状态筛选 Tab：学习中 / 待复习 / 已掌握（VOC-01）
- 原句语境翻转闪卡：正面单词 + 原句填空，背面释义 + 完整翻译 + 回溯入口（VOC-03/04）
- 底部评分：忘了（红）/ 模糊（橙）/ 记得（绿）（VOC-04）

### 学习进度
- 今日：观看分钟、完成片段、查词、复习
- 本周：有效学习日、常看主题、复习完成
- 词汇：学习中 / 已掌握 / 待复习

## 家长端（需 PIN）

### 家长控制台
- 4 位安全 PIN 模拟键盘（PRO-01）
- 大模型配置：Provider 协议切换（OpenAI 兼容 / Anthropic 原生）、API Base、模型名称、API Key 密码掩码、测试连接（8.18）
- 成员管理概览（不显示 API Key）
- 学习关怀设置入口（V1.1 预留）

## 设计风格
- 护眼教育晨曦蓝 + 薄荷绿主色，温和卡片圆角（16~24px）
- 触控热区 ≥ 48px，字号 18~20px，清晰层级
- 小米 15 Ultra 真机外壳：412×915 视口、极窄四等边、顶部微打孔、底部手势小白条
