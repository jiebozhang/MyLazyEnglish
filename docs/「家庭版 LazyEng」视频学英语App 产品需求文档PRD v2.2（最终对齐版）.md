## 1. Executive Summary

家庭版的核心是"看懂一小段，再记住几个词"。

MVP必须先闭合一条稳定链路：**家长导入合规视频与字幕 → 孩子逐句观看 → 点词获得即时解释 → 收藏到个人词典 → 回到原视频语境复习**。AI只负责增强解释、翻译与学习材料，绝不能成为基础功能的单点故障——即使AI完全不可用，孩子仍应能播放本地视频、查看英文字幕、使用基础词典、收藏词汇和复习。

| 维度       | 内容                                            |
| ---------- | ----------------------------------------------- |
| 主学习闭环 | 选视频 → 看字幕 → 点词 → 收藏 → 复习 → 回到原句 |
| 可交付形态 | Android APK（唯一路线，已锁定）                 |
| 商店依赖   | 无：不以应用商店发布为前提，家庭侧载安装        |

**交付优先级**

| 阶段       | 必须完成的价值                                             | 不提前做                 |
| ---------- | ---------------------------------------------------------- | ------------------------ |
| MVP / V1.0 | 本地视频、字幕联动、点词、本地词典、生词本、多档案、AI设置 | 复杂推荐、云账号、商业化 |
| V1.1       | YouTube官方播放、AI翻译/学习文本、授权媒体ASR、时长管理    | 开放社区、无限AI对话     |
| V2.0       | 复习算法优化、家长周报、可选跨设备同步                     | 排行榜、广告、UGC        |

## 3. Benchmark：参照产品能力边界

公开产品页将LazyEng描述为带交互字幕的英语视频播放器：用户可添加自有视频和字幕，也可使用YouTube；观看时点按生词查看翻译/语境含义，并把词保存到个人词汇表。

| 公开可验证能力               | 家庭版采用方式               | 证据边界               |
| ---------------------------- | ---------------------------- | ---------------------- |
| 电影、剧集、访谈、课程等视频 | 统一视频内容库               | 不复制其内容目录       |
| 自有视频与字幕               | 本地导入+字幕关联            | 格式与流程为本产品设计 |

## 4. 用户与场景

**主要用户：孩子（8岁）**

- 水平：已完成剑桥Power Up Starter/Power Up 2
- 任务：看懂喜欢的英文动画或短视频；生词不离开播放器；记住常见表达
- 约束：阅读耐心短、误触多、无法理解复杂词典语言；不应接触密钥与配置

**管理用户：家长**

- 任务：导入素材、关联字幕、配置AI模型、设置学习时长、查看学习进展，也可创建自己的独立档案学习
- 约束：不希望维护复杂后台；家庭自付AI成本需要可见且可控

**核心场景**

| ID    | 触发                 | 期望结果                              |
| ----- | -------------------- | ------------------------------------- |
| SC-01 | 放学后看8-12分钟动画 | 能逐句跟看，完成不被词典打断          |
| SC-02 | 遇到陌生词/短语      | 300ms内先看到基础义，随后补充语境解释 |
| SC-03 | 看完一集             | 得到5-8个本集重点词和简短回顾         |
| SC-04 | 家长添加新素材       | 来源、字幕、权限和处理状态清晰        |
| SC-05 | AI或网络失败         | 可继续播放/查基础词，不丢学习数据     |

## 5. 产品目标与验证指标

**产品目标**

- G1：孩子可在熟悉内容中持续接触真实语音，并在播放器内解决大多数理解障碍
- G2：每次点词都保留"词+原句+视频时间点"，让复习回到真实语境
- G3：家长能用最低配置成本准备素材、控制学习时长和AI费用

**MVP验证指标**

| 指标           | 建议口径                         | 用途           |
| -------------- | -------------------------------- | -------------- |
| 有效观看日     | ≥5分钟前台播放且完成≥3次字幕交互 | 衡量真正使用   |
| 有效片段完成率 | 已看完字幕句 ÷ 本次选定句        | 判断内容难度   |
| 查词收藏率     | 加入生词本 ÷ 去重查词            | 判断词典价值   |
| 7日语境复现率  | 7-14天后原句题首次正确           | 衡量记忆       |
| AI成功率       | 结构合法且无降级 ÷ 请求          | 监测模型可用性 |
| AI缓存命中率   | 缓存返回 ÷ 可缓存请求            | 控制成本       |

> 不作为目标：总停留时长、无限连播、连续打卡压力、查词越多越好。查词激增可能意味着内容过难。

## 6. 信息架构

**孩子端**（只保留四个高频入口）

- 首页：继续观看、推荐/最近导入、今日进度
- 视频库：封面列表、等级/主题/来源筛选
- 我的词典：学习中、已掌握、按视频来源筛选
- 我的进度：今日/本周时长、查词、复习与鼓励反馈

**家长端（需PIN）**

- 内容管理：导入、字幕、处理任务
- 成员管理：新建/切换/删除Profile
- 大模型设置：协议、地址、模型、密钥、超时、测试
- 学习关怀（V1.1）：连续提醒、每日上限、趋势

**导航规则**

- 播放页采用沉浸模式；返回时保存进度，不显示系统级配置入口
- 家长控制台入口放在"我的/设置"，进入需PIN；Android可选设备生物验证
- 内容处理任务只在家长端显示；孩子端仅看到"可观看/准备中/不可用"
- 切换Profile前立即落盘当前播放点、字幕位置和查词事件

主路径：**首页 → 视频详情 → 播放器 → 点词 → 生词本 → 原句复习**

## 7. 端到端流程

| 流程               | 关键步骤                                             | 完成条件             |
| ------------------ | ---------------------------------------------------- | -------------------- |
| F1 首次使用        | 建家庭→设家长PIN→建孩子档案→选水平→导入样例/自有素材 | 孩子进入可播放视频   |
| F2 本地导入        | 选视频→读元信息→自动/手动匹配字幕→预览→保存          | 详情页显示"可学习"   |
| F3 YouTube（V1.1） | 粘贴链接→官方播放器解析→检测字幕路径→关联字幕→保存   | 不下载视频且字幕可用 |
| F4 观看学习        | 播放→当前句高亮→点词→基础义→AI语境义→收藏            | 记录原句与时间点     |
| F5 复习            | 进入生词本→看/听原句→回忆词义→评分→更新状态          | 形成下一复习时间     |

**全局中断恢复**

- 应用被系统关闭后，重开恢复到视频详情，并提供"从XX:XX继续"
- 生成任务在后台持久化；重开后继续轮询，不重复扣费
- 切换网络、Profile或播放器来源时，未提交的点词请求可取消，已产生结果写入对应Profile
- 任何删除操作先显示影响范围；删除视频不自动删除该词在其他视频中的学习记录

## 8. 功能需求详述

### 8.1 Profiles（家庭多档案）

| ID     | 需求                  | 验收                                    |
| ------ | --------------------- | --------------------------------------- |
| PRO-01 | 首次创建家庭与家长PIN | PIN失败5次后等待；不泄露配置            |
| PRO-02 | 创建孩子/成人档案     | 头像、昵称、age_mode、英语水平；≤3步    |
| PRO-03 | 档案切换              | 首页、词典、历史、统计立即切换          |
| PRO-04 | 数据隔离              | 查询必须带profile_id；跨档案返回为空    |
| PRO-05 | 删除档案              | PIN二次确认；可选导出；后台任务一并取消 |
| PRO-06 | 家长查看成员概览      | 只展示汇总，不显示API Key               |

档案字段：`Profile { id, family_id, nickname, avatar_id, role, age_mode, english_level, ui_preferences, created_at, deleted_at }`

> MVP决策：不要求手机号/邮箱注册。跨设备同步放到V2.0；若后续加入云同步，Profile ID与家庭权限模型保持不变。

### 8.2 Home（首页）

**首屏结构**：当前Profile与切换入口 → "继续观看"主卡（封面/标题/进度/剩余时长）→ 今日进度（观看分钟/查词数/复习数）→ 我的词典摘要 **后续结构**：最近导入/推荐视频 → 按等级/主题浏览 → 处理提示（孩子端简化）→ 本周鼓励语与休息提示

| ID      | 规则                          | 空/异常状态                |
| ------- | ----------------------------- | -------------------------- |
| HOME-01 | 继续观看按last_watched_at排序 | 无历史则展示可播放首个视频 |
| HOME-02 | 今日在本地时区00:00重置       | 改时区不重写历史           |
| HOME-03 | 本周按周一至周日              | 无数据展示"开始第一段"     |
| HOME-04 | 推荐MVP用等级/主题规则        | 不足时显示最近导入         |
| HOME-05 | 处理失败内容不进入推荐        | 仅家长看到修复入口         |

### 8.3 Video Domain（视频领域模型）

**Video最小字段**

| 字段组 | 字段                                                         |
| ------ | ------------------------------------------------------------ |
| 标识   | id, source_type, source_ref, checksum                        |
| 展示   | title, cover_asset_id, duration_ms, topic_tags               |
| 学习   | cefr_level, subtitle_word_count, accent_tag, age_fit         |
| 状态   | import_status, subtitle_status, translation_status, playable |
| 权利   | owner_type, usage_note, added_by, source_terms_ack           |

**状态机**：`DRAFT → PROCESSING → READY → ARCHIVED`；失败分支：`PROCESSING → NEEDS_SUBTITLE / FAILED`（需带error_code和可执行修复建议）

**分级策略**：有人工等级优先人工值并记录来源；否则按字幕词频/句长/语速生成"建议等级"，标记为估算而非认证CEFR。儿童Profile默认隐藏age_fit=adult或unknown的内容，家长可覆盖。

### 8.4 Local Import（本地导入，V1.0）

支持格式（建议）：视频MP4/MOV/M4V（以系统播放器可解码为准）；字幕SRT/VTT（UTF-8优先，检测失败可手选编码）

| ID     | 需求                   | 验收                             |
| ------ | ---------------------- | -------------------------------- |
| IMP-01 | 从文件选择器选择视频   | 不读取未选择目录；取消不留脏数据 |
| IMP-02 | 提取时长、分辨率、音轨 | 解析失败显示原因，不创建READY    |
| IMP-03 | 同名字幕自动候选       | 必须由家长预览确认               |
| IMP-04 | 手动关联/替换字幕      | 替换保留旧版本，可回滚一次       |
| IMP-05 | 字幕前10句预览         | 时间、英文、乱码检查清晰         |
| IMP-06 | 重复文件检测           | checksum命中时提示复用或仍导入   |

存储策略：Android优先保存系统文件选择器授予的持久访问引用；需要复制进应用数据目录时先展示预计占用空间；删除只清理应用管理副本，不删除原文件。

### 8.5 YouTube（V1.1）

导入流程：粘贴链接（只接受可识别的YouTube视频URL/ID）→ 通过官方播放器/SDK获取标题/时长/封面（解析失败不猜测数据）→ 检测可用字幕路径（仅在平台条款和授权允许时获取字幕文本）→ 无字幕时提供"上传字幕"，"AI转写"仅在存在合法可处理音频输入时启用 → 保存source_ref与播放配置，不下载或永久缓存远端视频文件

| ID    | 规则                       | 失败处理                  |
| ----- | -------------------------- | ------------------------- |
| YT-01 | 只允许官方嵌入播放         | 受限视频提示在YouTube打开 |
| YT-02 | 地区/年龄/登录限制沿用平台 | 不可绕过；标记不可播放    |
| YT-03 | 字幕来源可追踪             | 未知来源不进入学习处理    |
| YT-04 | 网络断开不伪装离线可播     | 保留详情与字幕缓存说明    |
| YT-05 | 链接失效可重新检查         | 不删除既有学习历史        |

> YouTube字幕取得方式和ASR输入能力须在技术预研中验证，不能仅凭播放器"能播放"推断"能提取音轨/字幕"。

### 8.6 Subtitle Pipeline（字幕处理管线）

流程：SRT/VTT → 解析 → 时间轴校验 → 分句/分词 → 预览 → 发布版本

**处理规则**：统一为毫秒时间轴，保留原始文件hash/编码/解析器版本；结束时间不得早于开始时间，重叠超过阈值时提示（不静默改写）；字幕行过长按标点与时长建议拆分，保持原时间范围可回溯；英文token化保留标点与字符位置，点词需能映射回原句；发布后字幕版本不可变，更换字幕生成新版本，旧查词仍引用旧版本。

**验收**

| 检查      | 通过条件                                      |
| --------- | --------------------------------------------- |
| 编码      | 中文/英文无乱码；非法字节有提示               |
| 时间轴    | 抽测20句，偏差可手动整体校准                  |
| 空行/标签 | 无意义标签被安全清理，正文保留                |
| 版本      | 播放器、翻译和查词使用同一subtitle_version_id |

### 8.7 ASR语音识别（V1.1）

适用范围：优先支持本地视频或用户明确有权处理的音频；对YouTube仅当官方/授权方式可提供合法音频输入时启用，否则入口禁用并引导上传字幕。

| ID     | 需求                                       | 验收                     |
| ------ | ------------------------------------------ | ------------------------ |
| ASR-01 | 创建转写任务前确认语言、成本预估与权利声明 | 未确认不发起             |
| ASR-02 | 长音频分片，结果按时间轴合并               | 任务可暂停/取消/恢复     |
| ASR-03 | 显示进度：排队/转写/整理/完成              | 重复点击只返回同一job_id |
| ASR-04 | 允许家长预览和整体校准时间轴               | 确认后才发布             |
| ASR-05 | 低置信句标记                               | 不伪装为准确字幕         |

质量策略：保存provider/model/language/segment_confidence与任务费用区间；儿童内容中人名/拟声词/背景音乐易误识别，低置信片段允许手改；转写失败不影响视频实体，状态回到NEEDS_SUBTITLE。

### 8.8 Video Detail（视频详情页）

**孩子视图**：封面、标题、时长、建议等级、主题、观看进度、主按钮"观看/继续"；可选入口：学习文本、双语字幕、上下文词典（未生成时用易懂状态说明） **家长视图**：来源类型、字幕版本/状态、字数、处理任务、权利备注、重新关联、归档；可启动翻译/学习文本/ASR，并看到估算调用量

| ID     | 规则                                                       |
| ------ | ---------------------------------------------------------- |
| VID-01 | READY且有英文字幕时主按钮可用                              |
| VID-02 | 无字幕时孩子端不进入学习播放器；可由家长普通播放（可配置） |
| VID-03 | 等级显示"人工"或"估算"标识                                 |
| VID-04 | 受欢迎度MVP不展示；家庭样本不足，改为个人完播/最近观看     |
| VID-05 | 归档内容仍可从历史访问，默认不进入推荐                     |

> 设计取舍："受欢迎度"来自竞品截图概念，但家庭自用没有足够群体样本，MVP不制造虚假百分比。

### 8.9 Player（播放器，核心）

布局：上半区视频，下半区可滚动逐句字幕；横屏时视频为主，字幕使用侧栏或底部抽屉；当前句高对比高亮，不只依赖颜色

| ID     | 需求                              | 验收                               |
| ------ | --------------------------------- | ---------------------------------- |
| PLY-01 | 播放/暂停、拖动、音量、全屏、倍速 | 系统播放器行为一致                 |
| PLY-02 | 当前字幕随时间更新                | 本地视频目标误差\<300ms            |
| PLY-03 | 字幕自动滚到可视区                | 用户手动滚动后暂停跟随5秒          |
| PLY-04 | 单句复读                          | 按start/end循环；再次点击取消      |
| PLY-05 | 字幕模式                          | 英文/中文/双语；无翻译时禁用并说明 |
| PLY-06 | 退出保存进度                      | 每10秒与暂停/退出时落盘            |

儿童交互：主要触控目标不少于约44dp；点词时默认暂停2秒或由用户设置，关闭弹层后可选择继续播放；连续误点或重复点击不会生成重复AI请求。

### 8.10 Interactive Subtitles（点词交互）

点词解析顺序：根据字符范围取得surface form与完整字幕句 → 本地词形还原得到lemma（缩写/专名/数字先判定）→ 查询本地词典，立即展示基础信息 → 以word+sentence+subtitle_version发起/命中语境解释 → 用户点击"加入生词本"时保存原句、时间点与视频引用

| 特殊输入      | 处理                                           |
| ------------- | ---------------------------------------------- |
| 短语动词      | 先查单词；提供"选择短语"扩展，不自动猜过长范围 |
| 人名/地名     | 标记专名；不显示虚构词频/CEFR                  |
| 拼写错误      | 显示"字幕可能有误"，给候选但不自动替换         |
| 连字符/所有格 | 保持原字符范围，并尝试词形还原                 |
| 多词表达      | 允许长按选择；保存phrase类型                   |

去重：同一Profile、同一lemma、同一subtitle_line的连续点按只记一次lookup；UI可以重复打开，统计不重复累加。

### 8.11 Context Dictionary（语境词典）

弹层信息层级：① 核心：原形、发音按钮、音标、词性、当前语境下的简明中文义 ② 难度：词频级/CEFR，无可靠数据时不展示 ③ 语境：原句高亮、整句翻译、回到该时间点 ④ AI解释：一句简单解释+一条例句，异步加载 ⑤ 操作：加入/移出生词本、标记已会、复制（家长模式）、关闭

| ID     | 验收                                               |
| ------ | -------------------------------------------------- |
| DIC-01 | 本地命中后300ms目标内展示基础卡                    |
| DIC-02 | 无本地词条时显示原词，不阻塞AI查询                 |
| DIC-03 | AI加载不遮住基础义；可取消                         |
| DIC-04 | 发音失败可重试，不自动循环                         |
| DIC-05 | 每个保存词带source_video_id、line_id、timestamp_ms |
| DIC-06 | 复制/分享在儿童模式默认隐藏，可由家长开启          |

### 8.12 AI Context Explanation（AI语境解释）

**输入最小化**

```
{ word, lemma, sentence_en, previous_line_en?, next_line_en?,
  learner_level: "Power Up Starter-2", ui_language: "zh-CN" }
```

**输出契约**

```
{ meaning_zh, why_here_zh, simple_example_en,
  simple_example_zh, part_of_speech, confidence, safety_flag }
```

| ID     | 约束                               | 失败降级                 |
| ------ | ---------------------------------- | ------------------------ |
| AIC-01 | meaning_zh≤24字；why_here_zh≤80字  | 只显示本地释义           |
| AIC-02 | 例句使用低难度词汇，避免新生词堆叠 | 隐藏例句                 |
| AIC-03 | 不得编造视频剧情之外的信息         | 提示"暂时无法生成"       |
| AIC-04 | JSON Schema校验，字段清洗后展示    | 一次修复请求后停止       |
| AIC-05 | 同键结果缓存；家长可重新生成       | 保留旧结果直到新结果成功 |

提示词原则：解释"当前句中的意思"，不是列出词典全部义项；语气像耐心老师，不评价孩子，不引导继续聊天。

### 8.13 Learning Text（AI学习文本，V1.1）

输出结构：一句话摘要（中文40-80字）→ 重点表达（5-8个词/短语，须来自字幕并引用line_id）→ 情节/观点梳理（3-5条英文短句+简单中文）→ 理解题（3题，答案可从字幕找到）→ 亲子复述提示（2个简单问题）

| ID     | 规则                                               |
| ------ | -------------------------------------------------- |
| TXT-01 | 仅在字幕READY后生成；输入固定subtitle_version_id   |
| TXT-02 | 超长字幕分段摘要后再汇总；保留引用关系             |
| TXT-03 | 生成前显示估算调用量；家长确认                     |
| TXT-04 | 生成一次缓存；"重新生成"产生新版本，不覆盖成功旧版 |
| TXT-05 | 可离线查看；导出为本地PDF/Markdown放到P1后评估     |

验收：任一点到的重点表达都能跳回原句；若模型输出字幕中不存在的引文，校验失败且不发布。

### 8.14 Subtitle Translation（字幕翻译，V1.1）

流程：选择字幕版本 → 分批 → 模型翻译 → 行号校验 → 保存草稿 → 可用

| ID    | 需求                                  | 验收                     |
| ----- | ------------------------------------- | ------------------------ |
| TR-01 | 每批使用稳定line_id，不让模型改时间码 | 输入/输出行数一致        |
| TR-02 | 显示0-100%任务进度                    | 按已验证行数计算         |
| TR-03 | 上下文窗口带相邻句                    | 输出只返回目标句         |
| TR-04 | 失败批次可单独重试                    | 成功批次不重复调用       |
| TR-05 | 保留专名与语气一致性词表              | 同一角色名不漂移         |
| TR-06 | 字幕更新使翻译标记为STALE             | 旧版仍可查看，不自动混用 |

显示规则：播放器必须使用同一字幕版本的英文与中文；缺失某行翻译时只显示英文，不拿相邻行补位。

### 8.15 Vocabulary & Review（生词本与复习）

词条状态：`LEARNING（学习中）→ REVIEW（复习中）→ MASTERED（已掌握）`；另有`PAUSED（暂停）`

| ID     | 需求                           | 验收                       |
| ------ | ------------------------------ | -------------------------- |
| VOC-01 | 列表按最近、来源视频、状态筛选 | 切换过滤不丢滚动位置       |
| VOC-02 | 同lemma可有多个语境义          | 合并展示，语境记录独立     |
| VOC-03 | 闪卡正面显示词/音频            | 背面显示当前义、原句、跳转 |
| VOC-04 | 评分：忘了/模糊/记得           | 更新next_review_at         |
| VOC-05 | 已掌握可恢复                   | 历史事件保留               |

MVP复习规则：首次收藏→当天稍后；"忘了"→10分钟后；"模糊"→次日；"记得"→3天后；连续跨日"记得"后逐步拉长。所有参数可配置，V2.0再换成熟间隔算法。

### 8.16 Progress（学习进度）

**孩子视图**：今天（观看分钟/完成片段/查词/复习）、本周（有效学习日/常看主题/复习完成）、词汇（学习中/已掌握/待复习） **家长视图**

| 指标     | 口径                        | 建议文案               |

> 词汇量说明：不把"查过的词"直接等同于词汇量。MVP展示生词本状态；若未来估算词汇量，必须说明算法和误差，不用虚假精确数字。

### 8.17 Parent Console（家长控制台）

## 9. AI Contracts（AI能力契约）

| 能力     | 输入                     | 输出                   | 缓存键                            |
| -------- | ------------------------ | ---------------------- | --------------------------------- |
| 语境释义 | 词、当前句、相邻句、水平 | 当前义、解释、简单例句 | word+lineVer+promptVer+model      |
| 字幕翻译 | line_id批次、术语表      | line_id→中文           | subtitleVer+batch+promptVer+model |

**统一响应封装**

```
AIResult { request_id, feature, status, data,
  provider, model, prompt_version, cache_hit,
  latency_ms, usage_bucket, safety_flag, error_code }
```

**全局规则**：服务端/本地AI网关校验Schema，客户端不依据自由文本改变关键状态；失败最多自动重试1次，且仅限超时/临时网络，认证与配额错误不自动重试；提示词版本化，新版本不覆盖旧缓存，允许逐步重生；发送最少上下文，不发送昵称、年龄精确值、观看历史全量或API Key。

## 10. Cost & Cache（成本与缓存）

调用优先级：**本地词典 → 本地缓存 → 家庭共享缓存 → AI请求 → 保存版本**

| 策略   | 规则                                               |
| ------ | -------------------------------------------------- |
| 去重   | 同一幂等键只允许一个进行中任务                     |
| 批处理 | 字幕翻译按token上限分批，失败批次单独重试          |
| 预算   | 家长可设每日/每月请求或费用上限；达到后停止新任务  |
| 可见性 | 展示调用次数、缓存命中、估算用量；不假装是精确账单 |
| 清理   | 清缓存可选媒体/AI/临时文件；已发布生成内容默认保留 |
| 版本   | 模型或prompt变化产生新键，不静默混用               |

并发：语境解释前台优先；字幕翻译与学习文本后台低优先；ASR单设备同时最多1个。前台请求不被长任务占满连接池。

> 费用口径：不同Provider返回的token/金额字段不一致。MVP记录标准化usage_bucket与原始可用量；"费用"只做估算，并明确不是供应商账单。

| AIGeneratedContent | id, feature, cache_key, input_ref, output_json, version, status |
| AIJob              | id, feature, status, progress, error_code, usage             |
| LearningSession    | id, profile_id, started_at, active_seconds, ended_reason     |
| TimeLimitOverride  | profile_id, minutes, authorized_at, local_date               |

事件规则：LookupEvent、ReviewAttempt只追加，不回写，统计由事件聚合；VocabularyItem是当前快照，可从事件重建；AI输出保存Schema版本与安全标志，坏输出不标记READY；所有本地事件有UUID，未来云同步按幂等键去重。

## 12. API Contract（接口契约）

接口按资源与异步任务拆分，所有写操作可幂等：

| 方法与路径             | 用途                     | 关键约束              |
| ---------------------- | ------------------------ | --------------------- |
| GET /profiles          | 成员列表                 | 家长/本地权限         |
| POST /videos/import    | 创建导入任务             | 幂等键；返回job_id    |
| POST /videos/youtube   | 保存官方播放引用（V1.1） | 不接收下载内容        |
| POST /subtitles/import | 上传/关联字幕            | 版本化；预览后发布    |
| GET /videos/{id}/lines | 分页取字幕               | 固定version_id        |
| POST /lookups          | 记录点词                 | profile_id+event_uuid |

| POST /ai/jobs          | 翻译/文本/ASR（V1.1）    | 异步；预算预检        |
| GET /ai/jobs/{id}      | 任务进度                 | 可恢复轮询            |
| POST /reviews          | 提交复习评分             | 幂等；更新快照        |
| GET /stats/weekly      | 周报                     | 返回口径与样本状态    |

> 若MVP完全本地实现（无独立后端服务），可将同一接口定义为repository/service边界；不要让UI直接跨表查询，以便未来接入同步。

## 13. 架构选型（已锁定：Android）

**技术栈**：Kotlin + Jetpack Compose；Media3/ExoPlayer；Room（SQLite）；WorkManager；Android Keystore **交付**：签名APK，家庭设备侧载安装，无需应用商店审核

**共用领域模块**：Profiles、Library、Playback、Subtitles、Dictionary、Vocabulary、AI Gateway、Reports——实体与接口契约保持一致，便于未来演进（如加入云同步或其他客户端）

**可选家庭服务**：首版不设服务器；长时ASR可由本机worker执行；只有确需多设备同步时再增加家庭局域网服务

> 范围规则：不得同时维护多套UI（如Android+Web/桌面）。领域模型、数据库迁移和AI契约按可复用方式设计，为未来可能的扩展留出空间。

## 14. 离线与同步

**离线矩阵**

| 能力            | 离线行为               | 联网后               |
| --------------- | ---------------------- | -------------------- |
| 本地视频        | 可播放                 | 无额外动作           |

## 15. 状态与错误码

| 错误码               | 用户文案               | 可执行动作           |
| -------------------- | ---------------------- | -------------------- |
| NO_SUBTITLE          | 这个视频还没有英文字幕 | 上传字幕/家长处理    |
| VIDEO_UNAVAILABLE    | 视频暂时无法播放       | 重试/在官方应用打开  |
| AI_NOT_CONFIGURED    | AI功能还未设置         | 进入家长控制台       |
| AI_AUTH_FAILED       | 模型连接验证失败       | 检查地址、模型和密钥 |
| AI_BUDGET_REACHED    | 已达到本月AI限额       | 使用缓存/家长调整    |
| AI_OUTPUT_INVALID    | 这次解释没有生成成功   | 重试一次/看基础释义  |
| STORAGE_LOW          | 设备空间不足           | 清理缓存/取消导入    |
| SUBTITLE_OUT_OF_SYNC | 字幕时间可能不准确     | 家长整体校准         |

> 状态文案原则：孩子端不展示Provider、HTTP、token或堆栈；家长端显示可诊断错误类型，但仍不显示密钥和完整响应。所有重试按钮必须幂等。

## 17. 安全、隐私与版权

**安全与隐私**

- 最小化收集；MVP不需要真实姓名、生日、手机号或精确位置
- API Key只通过系统安全存储读取；禁止进入日志、崩溃上报、剪贴板和导出
- 家长PIN采用带盐哈希；连续失败限速；敏感设置二次验证
- 本地数据导出/删除由家长发起；删除前说明哪些缓存和历史会消失
- 若向第三方模型发送字幕片段，家长首次启用时应看到数据范围与供应商责任说明

**媒体与平台权利**

- 用户只导入有权使用的本地视频和字幕；产品保存权利备注但不替用户判断版权
- YouTube只使用官方播放方式，不下载视频、不绕过地区/年龄/登录限制
- 字幕抓取、音轨提取和ASR必须有合规技术路径；不可用时提供上传字幕，不做规避
- 竞品内容、截图、图标、文案、词库和算法不复制；只参照公开能力

## 22. 风险与剩余问题

| 风险                           | 影响               | 处理                                |
| ------------------------------ | ------------------ | ----------------------------------- |
| YouTube字幕/音频不可合法取得   | 翻译、ASR无输入    | 先验证官方能力；默认上传字幕        |
| 模型输出不稳定                 | 儿童解释质量波动   | Schema、长度、缓存、失败降级        |

| ECDICT许可证适用范围未最终核实 | 词典数据可用性风险 | 技术预研阶段确认，必要时更换数据源  |
